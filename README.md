# Chronogramme

> [!WARNING]  
> This library is not currently in active development.

Chronogramme is a timeline library for the web.

It currently contains 2 packages:
1. `chronogramme`, the core library using Web Components with no runtime dependencies.
2. `chronogramme-rct`, a React binding that mirrors a subset of the 0.27.3-beta interface for the [React Calendar Timeline](https://www.npmjs.com/package/react-calendar-timeline) library.
